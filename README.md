# Hamza Abdul Abed - Portfolio (v2)

Static site: no build step. Open `index.html` or use VS Code Live Server.

## Files
- `index.html` content and structure
- `style.css` design tokens are at the top (`:root`)
- `script.js` menu, scroll progress, project rows, hero animation, contact form
- `assets/Hamza_Abed_CV.pdf` CV download
- `assets/screenshots/` drop project screenshots here

## Add a real screenshot
Save a 16:10 image as `assets/screenshots/malela.jpg`. It replaces the placeholder automatically.

## Edit projects
Each project in the list is one `<li class="row">`. Replace the "coming soon" lines with links when demos exist.
